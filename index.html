字幕翻譯室是什麼？

這是一個免費的網頁工具，把英文 SRT 字幕翻成台灣慣用語的繁體中文。翻完之後可以直接在表格裡逐句修改，再下載成新的 .srt 檔，不需要註冊帳號。

  • 免費模式：使用桌面版 Chrome 內建翻譯，在你自己的電腦上翻譯，字幕不會上傳。品質屬草稿級，建議逐句檢查。
  • 進階模式：貼上你自己的 Anthropic API key，使用 Claude 翻譯，可選自然口語、正式書面或戲劇化風格。
  • 台灣用語：免費模式會自動把常見的中國用語換成台灣用語，並可用「批次修正」一次改掉重複的錯誤。

請只處理你有權使用的字幕。原始碼以 MIT 授權公開在 GitHub。
